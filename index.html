Детально по кампаниям

Одна секция — одна неделя. Поведение и цели — из Метрики по последнему значимому переходу.
Как считаем обращения. «Заявка» — показ страницы «Спасибо» после отправки формы, эту цель оплачивают кампании B2C. Цель «Спасибо» срабатывает на сайте только с апреля 2026, поэтому для более ранних периодов смотрите колонку «Все обращения»: заявка + корпоративная форма + клик по телефону + переход в Telegram/WhatsApp. Один человек может сделать несколько действий, поэтому обращения — это действия, а не уникальные клиенты.
Расход при оплате за конверсии. Кампании B2C списывают деньги за конверсию, а не за клик, поэтому у недели может быть много кликов при нулевом расходе. Суммы — без НДС.
Сделки. Колонку «Сделки» заполняете вы — в строке «Итого» каждой недели и каждого месяца. Число сохраняется сразу и видно всем, у кого есть ссылка; стоимость сделки = расход ÷ сделки.
